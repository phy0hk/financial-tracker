## Section 6 Deliverables

- `packages/core/src/plugins/modules/CoreExpenseModule.ts`
  - Implements `IAppModule` with SQLite/PostgreSQL category and expense migrations.
  - Exports/imports encrypted expense and category records through an optional database adapter or memory fallback.
  - Contributes expense navigation and dashboard widgets.
- `packages/core/src/plugins/modules/EmergencyDuressModule.ts`
  - Verifies a secondary PIN using a salted WebCrypto SHA-256 digest.
  - Creates and destroys an isolated ephemeral in-memory SQLite-compatible database containing dummy transactions.
- `packages/core/src/plugins/modules/OCRScannerModule.ts`
  - Uses a locally supplied Tesseract.js browser API/worker.
  - Extracts raw text, date, vendor, and total locally from an image `Blob`; no upload path is used.
- `packages/core/src/plugins/modules/SubscriptionsModule.ts`
  - Provides recurring subscription migrations, CRUD-like in-memory management, upcoming renewal calculation, and monthly overhead totals.
- `apps/web/src/screens/AdminScreen.tsx`
  - Restricts the screen to the authenticated `admin` role.
  - Implements paginated user listing, block/unblock, and delete actions against the protected admin API.
- `apps/web/src/App.tsx`
  - Registers all four concrete modules with `PluginManager`.
  - Mounts `AuthProvider`, `StorageProvider`, and a browser-history client router.
  - Provides `/auth`, `/dashboard`, `/settings`, and `/admin` route behavior.

## Running the Workspace

```bash
bun install
bun dev
```

Run typechecking with:

```bash
bun run typecheck
```

The current typecheck has one pre-existing TypeScript DOM `BufferSource` diagnostic in `packages/core/src/crypto/index.ts:163`; the Section 6 files introduce no additional diagnostics. Production deployment still requires `JWT_SECRET`, database/Hyperdrive configuration, and a real `VITE_API_URL`. Tesseract.js must be bundled or loaded locally by the web host before invoking `OCRScannerModule.scan()`.
